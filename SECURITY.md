# Security Policy

## Supported Versions

Security fixes are provided for the latest released version and the `main` branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not open a public issue for sensitive security vulnerabilities.

Instead, report vulnerabilities privately via GitHub's private vulnerability reporting for this repository (if enabled), or contact the maintainers through a private channel.

When reporting, include:

- A clear description of the issue and potential impact
- Steps to reproduce or a proof of concept
- Affected versions/commit (if known)
- Any suggested mitigation

We will review reports as quickly as possible and coordinate a fix and disclosure timeline when appropriate.
